# Step 9 content-presentation audit — Days 1–14

**Status:** Internal implementation audit. This document records presentation decisions; it does not alter the canonical curriculum.

| Area | Observed presentation gap | Handling in the learner MVP |
| --- | --- | --- |
| Daily targets | The canonical fields were present but the dashboard exposed only the objective. | Added source-derived target cards for objective, grammar/pattern, pronunciation, Daily German Core, Sentence Builder, and practical mission. |
| Daily German Core | Core items appeared as raw Markdown within the lesson. | Added a separate lightweight Core panel that extracts the approved German item and its supplied meaning/type/register wording. It does not invent active/receptive labels. |
| Pronunciation | Day-level guidance existed, but Day 5's required complete alphabet reference was not reusable. | Added a dedicated alphabet/spelling reference from Day 5 onward, labelled as introduced in Day 5 and with “Audio unavailable” rather than fabricated audio. |
| Sentence building | The canonical source task was interactive but its varied source stages were not visible. | Added a source-derived construction-stage indicator and retained the canonical answer/retry interaction. |
| Practical and repair language | Both existed but competed visually with all other raw sections. | Promoted them to named flow stages with distinct mission and repair presentation. |
| Listening/audio | The curriculum specifies listening practice, but no approved audio assets or URLs are present. | Preserved text-based listening instructions and explicitly show audio as unavailable. No content or audio was invented. |
| Open-ended speaking/writing | Canonical prompts exist, but there are no approved deterministic answer keys for automatic scoring. | Kept learner-completed practical/retrieval actions formative and self-marked. Automated scoring and AI feedback remain outside this step. |

No curriculum content, chronology, grammar dependency, Daily German Core order, or final-QA correction was changed. Days 15–42 remain unavailable.
